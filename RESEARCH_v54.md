**Дата:** 2026-10-10

## 1. Честная формулировка v5.4.1

`ZeroResp v5.4.1` — это **не** улучшенный релиз и не победная стратегия. Это узкий экспериментальный патч, решающий конкретную проблему: **хвостовой риск штопора (spin-out) против строгих реципрокаторов памяти (`TwoTitsForTat` и `Gradual`)**.

### Фактический профиль v5.4.1:
1. **Детерминированное ядро (29 оппонентов):** Поведение бит-в-бит идентично `v5.3` (дельта SPT ровно $0.000000$).
2. **Строгие реципрокаторы (5% шум):** Вероятность взаимного штопора снижена с 23.3% до 0.0% на TTFT ($\Delta = +0.37$ SPT) и с 33.3% до 10.0% на Gradual ($\Delta = +0.26$ SPT).
3. **Плата за великодушие на Holdout 40 (5% шум):** $\Delta = -0.0302$ SPT ($p = 0.007$).
4. **Уязвимость перед хаосом (Random, 5% шум):** Худший сид падает до $-1.055$ SPT (141 C / 59 D против 50% дефектора).
5. **Итог:** Модель **не готова к релизу** и зафиксирована как `wip/experimental`.

## 2. Главный научный результат: «How the v5.4 rank gain turned out to be a measurement artifact»

В ходе ZDB-протокола было сделано критическое открытие: **заявленный «прорыв» v5.4 (ранг 4/225 в круговом турнире) был артефактом измерения на сверхмалом подмножестве оппонентов.**

### Механизм возникновения иллюзии:
1. В круговом турнире Axelrod на 225 стратегий присутствуют циклические боты (`Cycler CCD`, `Cycler CCCD`, `Cycler CCCCCD`, `AntiCycler` и др.).
2. В базовой версии `v5.3` эти стратегии эксплуатировались штатно (3.535 на `Cycler CCD`, 4.485 на `AntiCycler`).
3. При ручных тестах и агрегации рангов высокий балл формировался гипер-чувствительностью турнирной таблицы к горстке вырожденных ботов:
   - В круговом зачёте победа с огромным перевесом ($>3.5$ SPT) над 3–4 цикликами способна поднять общую позицию на десятки мест вверх, создавая видимость системного улучшения.
4. При включении `balance_apology` в v5.4 и попытке адаптироваться к шуму алгоритм стал принимать циклические дефекты оппонента за повод для уступок и балансировки:
   - На `Cycler CCD` счёт обвалился с **3.535 до 2.040** ($\Delta = -1.495$).
   - На `AntiCycler` счёт упал с **4.485 до 2.730** ($\Delta = -1.755$).
5. **Вывод:** «Ранг 4/225» в IPD-турнире нестабилен и маскирует локальные разрушения логики. Оценка прогресса по агрегированному рангу без парной seed-by-seed декомпозиции — методологическая ошибка.

## 3. Анатомия Random-коллапса

В v5.4/v5.4.1 механизм `balance_apology` запускался по условию:
$$\text{nl\_balance} \le -4 \quad \text{и} \quad \neg (\text{opp\_len} \ge 15 \land \text{live\_coop\_rate} < 0.60)$$

Проблема условия:
- Случайный оппонент (`Random`, $p=0.5$) с вероятностью $\approx 10\%$ в первые 15 раундов случайно выбрасывает $\ge 60\%$ коопераций (например, сиды 48 и 54).
- `ZeroResp` классифицирует его как «партнёра, обиженного нашим шумом», стирает историю обид, задирает `warmth = 0.60` и ставит `echo_forgive = 2`.
- В результате `ZeroResp` играет 141 C против случайного дефектора, получая разгромный счёт $1.88$ вместо нормальных $2.78$.

## 4. Архитектурное направление v5.4.2: Гейт отзывчивости (Responsiveness Gate)

Для устранения уязвимости без потери защиты от штопора в `v5.4.2` балансировка не должна полагаться на статическую долю кооперации. Требуется **гейт условной вероятности (отзывчивости)**:

$$\Delta P_{\text{resp}} = P(\text{Opp } C \mid \text{Our } C) - P(\text{Opp } C \mid \text{Our } D)$$

- **Для реципрокаторов (`TTFT`, `Gradual`, `TFT`):** $\Delta P_{\text{resp}} \approx 1.0 - 0.0 = 1.0 \gg 0$. Наш ход прямо управляет поведением оппонента. Извинение имеет смысл.
- **Для `Random`:** $P(\text{Opp } C \mid \text{Our } C) \approx 0.5$, $P(\text{Opp } C \mid \text{Our } D) \approx 0.5 \implies \Delta P_{\text{resp}} \approx 0.0$.
- **Для безусловных дефекторов / цикликов:** $\Delta P_{\text{resp}} \le 0.0$.

Балансировка `balance_apology` должна иметь строгое право на запуск только если:
$$\Delta P_{\text{resp}} \ge \theta_{\text{resp}} \quad (\text{например, } \theta_{\text{resp}} = 0.35)$$
