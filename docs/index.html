Quick start

import axelrod as axl
from zeroresp import ZeroResp

match = axl.Match((ZeroResp(), axl.TitForTat()),
    turns=200, seed=0)
match.play()
print(match.final_score())

Install Axelrod, drop in zeroresp.py, run a match. Ladder is on by default.
