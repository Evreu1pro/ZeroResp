# ZeroResp v5.4: закрытие по битовому совпадению с v5.3

**Дата:** 2026-10-11.
**Статус:** проверка завершена. v5.4 **побитово инвариантна** v5.3 на всём протоколе.
**Файлы-источники:** `benchmarks/seed_breakdown.py`, `benchmarks/results/seedbreak_v5.3_vs_v5.4_*.json` (4 файла), `benchmarks/preregistrations/C0_ladder_off_equivalence.md`.

## Протокол

- Оппонент: `--pack full`, 221 оппонент.
- Сиды: 30, с 42 по 71.
- Длина: 200 ходов.
- Уровни шума: 0, 0.05, 0.10, 0.20 (iid action flip).
- Сравнение: **вся история ходов по позициям** для обоих игроков на каждом матче. Итого `4 × 30 × 221 = 26 520` матчей.

## Результат

| Уровень шума | Матчей | Расхождений |
|---|---|---|
| 0.00 | 6 630 | 0 |
| 0.05 | 6 630 | 0 |
| 0.10 | 6 630 | 0 |
| 0.20 | 6 630 | 0 |
| **Всего** | **26 520** | **0** |

История обоих игроков совпадает побитово на всех матчах. Это сильнее, чем совпадение по SPT: v5.4 принимает **те же решения на каждом ходе**.

## Расхождение с ожиданием

Проверка планировалась так: «пройдёт чисто на 10%/5% и даст ожидаемые расхождения на 0%». Ожидание не подтвердилось — расхождений **нет ни на одном уровне, включая 0%**.

Это меняет интерпретацию. Если бы v5.4 расходилась на 0%, можно было бы сказать, что она влияет на поведение, но в шуме разница растворяется. Фактически v5.4 не влияет на поведение вообще: ни в тишине, ни под шумом. Значит, изменения, внесённые в `zeroresp_v54.py` относительно `zeroresp.py` (по diff: 89 строк добавлено, 7 удалено), на данном протоколе **не достигают точки принятия решения** ни разу.

## Вывод

1. v5.4 не даёт ни улучшения, ни ухудшения на протоколе 221 оппонент × 200 ходов × шум 0–20%.
2. Её ранг и SPT совпадают с v5.3 не «по округлению», а по факту: это одна и та же стратегия в наблюдаемом поведении.
3. **Не проверено:** другие длины матчей, другие матрицы выплат, другие модели шума. Инвариантность установлена только для этого протокола.

## Что это значит для выбора версии

v5.4, v5.4.1 и v5.4.2 на этом протоколе неотличимы от v5.3. Поэтому T1 проводится на v5.3 как базовой, и добавление v5.4.x в число контролей научной информации не даёт. Контроли T1: «v5.3 с ladder off» (проверено C0) и v5.5 (установленная регрессия).
