# Pre-registration T4: внешний hold-out (не Axelrod)

**Date:** 2026-10-11 (до запуска прогонов; HEAD `af922d2`)
**Статус:** пул не собран. Регистрация фиксирует дизайн до сборки.

## Hypothesis

ZeroResp v5.3 входит в топ-5 при iid-шуме 10% на внешнем пуле, не входящем в библиотеку Axelrod.

## Criterion

- Медианный ранг ≤ 5 по сидам при iid 10%.
- Ранг считается в пуле из внешних стратегий плюс ZeroResp.

## Design

Пул 20–30 стратегий из источников вне `axelrod`:

- Литературные: Wu & Axelrod, Fudenberg-Maskin, Stewart-Plotkin ZD (ZD-Extort, ZD-GEN). Ни одна из них не должна попадать в `axelrod.strategies` под тем же именем.
- Случайные FSM с числом состояний 2, 4, 8, 16 (по 5 каждого размера, фиксированные сиды генерации).
- Внешние библиотеки или реализации авторов — только если код читается и воспроизводим.

Правила:

- Пул фиксируется до запуска. Стратегии, добавленные после первого прогона, в анализ не входят.
- Сиды: 30; длина 200 ходов; шум iid 10%.
- Дубликаты с Axelrod исключаются по поведению (совпадение истории на 200 ходах при 0% шуме).

## Analysis

- Ранг по сидам, медиана и доля сидов с рангом ≤ 5.
- Holm-Bonferroni при сравнении с 0% и 5%.
- Jackknife по стратегиям пула (исключение одной за раз): критерий должен выполняться в большинстве подвыборок.

## Prediction

Ожидаю ранг 3–7. Топ-5 вероятен, но не гарантирован: пул из FSM случайного размера может содержать сильные стратегии, которых нет в Axelrod.

## Known risk

Пул 20–30 стратегий даёт ранг с большей дисперсией, чем 222. Критерий «топ-5 из 25» менее строгий, чем «топ-5 из 222», и результат нужно интерпретировать с этим поправкой.
