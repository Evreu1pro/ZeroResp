# Pre-registration T11: экологическая динамика популяции

**Date:** 2026-10-11 (до запуска прогонов; HEAD `af922d2`)

## Hypothesis

H1: при 5% шуме ZeroResp v5.3 сохраняет долю в популяции ≥ 50 поколений.

H2: при 10% шуме ZeroResp доминирует (к концу симуляции занимает наибольшую долю).

## Criterion

- H1: доля ZeroResp в популяции > 0 на поколении 50 в ≥ 80% сидов.
- H2: средняя доля ZeroResp на поколении 100 ≥ 0.50 по сидам.

## Design

- Популяция: `--pack field` (32 стратегии), по 1 экземпляру стратегии на тип, начальные веса равны.
- Поколения: 100.
- Один шаг: раунд-робин каждой пары в популяции на 200 ходах с шумом, счёт каждой стратегии = сумма очков против всех.
- Репликация: вес стратегии на следующем поколении ∝ её счёту за поколение; стратегии с долей < 0.01 удаляются.
- Сиды: 30.
- Шум: 5% и 10% iid.

## Implementation note

Стратегии с состоянием (ZeroResp, TFT-семейство) создаются заново для каждого матча, чтобы не переносить историю между поколениями. Это фиксируется в коде до запуска.

## Analysis

- Траектории долей по поколениям, медиана и 95% доверительный интервал по сидам.
- Доля ZeroResp на поколениях 50 и 100.
- Сравнение с TFT (тот же протокол): Wilcoxon по сидам на поколении 100.

## Prediction

Ожидаю H1 выполненным при 5%. H2 по доминированию вероятно не выполнится: при репликации по счёту AllD и хищные стратегии часто получают больший счёт в короткой перспективе. Если H2 не подтвердится, это будет зафиксировано как отрицательный результат.
