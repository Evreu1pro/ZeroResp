# ZeroResp v5.5: отрицательный результат против v5.3

**Статус:** установлен на paired-протоколе. Не относится к pre-reg T1.
**Файлы-источники:** `benchmarks/results/paired_v5.3_vs_v5.5_20261011_125934.json`, `benchmarks/results/seedbreak_v5.3_vs_v5.5_20261011_140209.json`, `benchmarks/paired_delta.py`, `benchmarks/seed_breakdown.py`.
**HEAD на момент прогона:** `af922d2`.

## Протокол

- Базовая версия: v5.3 (`zeroresp.py`). Сравниваемая: v5.5 (`zeroresp_v55.py`).
- Пул: `--pack full`, 221 оппонент.
- Шум: iid action flip, 10%.
- Длина матча: 200 ходов.
- Сиды: 30, с 42 по 71. Пары: одинаковые сиды и оппоненты для обеих версий.

## Результат

| Метрика | Значение |
|---|---|
| mean SPT v5.3 | 2.3548 |
| mean SPT v5.5 | 2.3031 |
| Δ = v5.5 − v5.3 | **−0.0517** |
| 95% bootstrap CI | [−0.0637, −0.0377] |
| Wilcoxon p (two-sided) | 2.3e-6 |
| Сиды с Δ < 0 | 28 из 30 |
| Сиды с Δ ≈ 0 (|Δ| < 0.005) | 1 (сид 61: +0.0009) |
| Сиды с Δ > 0 | 1 (сид 71: +0.0802) |

Отдельно: сид 43 имеет Δ = −0.0072, то есть он отрицательный и входит в 28 сидов. Ранее в обсуждении он ошибочно назывался «не в минусе».

## Что видно на уровне сидов и оппонентов

**Сид 61.** Истории совпадают на 81 из 221 оппонента. На остальных 140 разница есть, в обе стороны: от −2.27 (Hopeless) до +1.69 (CycleHunter). Среднее Δ ≈ 0 получено сокращением противоположных эффектов, а не отсутствием активации фичи.

**Сид 71.** Истории совпадают на 40 из 221. Выигрыш v5.5 сконцентрирован на HardGoByMajority (+1.52…+1.68) и Forgiver-подобных стратегиях. Проигрыш — на Hopeless (−2.48), EvolvedLookerUp2_2_2 (−1.97), EvolvedFSM16 (−1.54), MathConstantHunter (−1.44), EasyGo (−1.38).

## Выводы

1. **Регрессия реальна на уровне среднего** и устойчива по сидам: 28 из 30 сидов отрицательны.
2. **Среднее скрывает структуру.** Отдельные матчи сдвигаются на ±1.5 SPT. v5.5 меняет поведение, а не просто немного ухудшает его. Эффект знакоперемен по оппонентам.
3. **Сид 61 не доказывает, что фича спит.** Он показывает, что положительные и отрицательные эффекты взаимно компенсируются.
4. **Механизм не установлен.** Какая именно часть v5.5 (относительно v5.3) отвечает за проигрыш на Hopeless/EvolvedLookerUp и выигрыш на HardGoByMajority, в этом документе не выяснено. Это следующий шаг: ablation по изменениям v5.5.

## Что не проверено

- v5.6 на 30 сидах: в `versions_*.md` он даёт те же цифры, что v5.5, но парный тест не запускался.
- Другие уровни шума.
- Модели шума, отличные от iid.

## Статус

Регрессия установлена для одной версии на одном пуле и одном уровне шума. Не обобщается на другие версии без собственного парного теста.

## Пересчёт и сиды 61 и 71 (добавлено)

**Инструмент.** Первый прогон Δ = −0.0517 сделан до исправления сидирования игроков. Пересчёт с исправленным \paired_delta.py\ дал те же значения: Δ = −0.05167, p = 2.3e-6. Сидирование не влияло на этот тест, потому что оба варианта создаются в одном порядке. Вывод регрессии не меняется.

**Сид 71: фича помогает на части оппонентов.** v5.5 выигрывает на HardGoByMajority-семействе (+1.52…+1.68) и проигрывает на Hopeless (−2.48), EvolvedLookerUp2_2_2 (−1.97), EvolvedFSM16 (−1.54). Средний Δ сида +0.080 положителен. Это режим, где v5.5 лучше v5.3.

**Сид 61: эффекты взаимно гасятся.** Истории совпадают на 81 из 221 оппонента, на остальных 140 различаются в обе стороны (от −2.27 до +1.69). Средний Δ ≈ 0 получен компенсацией, а не отсутствием активации фичи. Вывода «фича спит» здесь делать нельзя.

**Что это меняет.** Регрессия — свойство среднего по пулу. На уровне сидов v5.5 не везде хуже: есть сиды (71), где v5.5 лучше. Для scope condition нужен отдельный тест: что отличает сид 71 от остальных (тип оппонентов в пуле, а не сам сид). Этот тест не проведён.
