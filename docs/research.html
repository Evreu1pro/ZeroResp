What each new version is

v5.4.2
responsiveness-gated apology: ΔPresp = P(C|our C) − P(C|our D) ≥ 0.35. Keeps the spin-out fix, halves the Random cost of v5.4.1 (−0.093 → −0.047).
v5.4.3
noise-level contour switch (quiet → static gate, noisy → responsiveness gate). Honest negative result: under channel noise it converges to v5.4.2 — the responsiveness gate already is the right switch.
v5.4.4
cycler contour: fixed-period detection (periods 2–6, window 18, noise-tolerant, mirror-guarded) blocks the apology — the aggressive base contour keeps exploiting. Best of ours at 5% noise.

Honesty audit

Does the model know its opponents?

overfitting audit

No opponent names appear in the decision logic — zero branches of the form "if it is X, do Y". All behavior is inferred from the current match: noise estimation, responsiveness gate, period detection, evidence ladder, tactical classifier.

Profile memory
learned stats keyed by opponent name across rematches; inactive in single matches; declared via manipulates_state; switchable off
Tuned constants
thresholds tuned on the reporting pool; external holdout showed −0.03 (recorded honestly)
Meta-lessons
some fixes motivated by specific dev seeds; mechanisms stay generic and replicate on fresh seeds
Context
the strategies above us (Evolved ANN 5 Noise 05 et al.) were literally evolved against this library — our rules are readable and auditable instead
